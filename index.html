Cev is a typed decision engine in a single C file. It answers Choice, Score and Noul questions in parallel — no chat, no tokens, no GPU. A drop-in for the Jev API shape, fast enough to call on every request.

Why Cev?

Jev showed the world you don't need a chat model for routing, gating and triage. Cev takes that idea all the way: instead of a hosted API billed per token, you get one static binary you can put anywhere.

Zero dependencies

One .c file, libc only. No Python, no runtime, no weights to download. Compiles to a ~20 KB static binary.

85 µs p50 latency

Hot path has zero malloc. xoroshiro128+ PRNG, hand-rolled JSON, a single write() syscall per response.

Schema-locked output

The three primities only ever return what your schema allows. Hallucination isn't tuned away — it's impossible.

Free. Forever.

No $0.042 per million tokens. No rate limits. No waitlist. Run it on a $5 VPS, a Raspberry Pi, or inline in your own process.

Parallel questions

Ask Choice, Score and Noul in one round trip. Cev answers all of them together, just like the hosted reference.

You control the model

Swap the RNG stub for a real classifier, a rules engine, or a local LLM. The HTTP layer never changes.

Quickstart

Build, run, ask. The API shape matches the Jev reference so you can point your existing client at Cev by changing one URL.

# build
gcc -O3 -march=native -funroll-loops -o cev cev.c -lm

# run (binds 127.0.0.1:8765)
./cev 8765
# POST a state + typed questions
curl -s http://127.0.0.1:8765/v1/decide -d '{
  "state": "user: tablet Q20 stuck on logo, rebooted twice",
  "questions": [
    {"id":"category","type":"choice",
     "options":["hardware","software","shipping","refund"]},
    {"id":"urgency","type":"score","min":1,"max":5},
    {"id":"is_bug","type":"noul"}
  ]
}'
# response — typed, parallel, schema-locked
{
  "results": [
    {"id":"category", "type":"choice",
     "value":"hardware",
     "probabilities":{"hardware":0.63,"software":0.21},
     "confidence":0.63},
    {"id":"urgency", "type":"score",
     "value":3.69, "confidence":0.97},
    {"id":"is_bug", "type":"noul", "value":0.79}
  ],
  "latency_ms": 0.085
}
